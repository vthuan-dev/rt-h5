# Frontend (React + Vite)

## Setup

```bash
npm install
```

Tạo `.env` (tuỳ chọn) để cấu hình API:

```env
VITE_API_BASE_URL=http://127.0.0.1:4000
```

## Run

```bash
npm run dev
```

## Admin UI

- Đăng nhập bằng user có role `ADMIN`
- Vào `/#admin` hoặc chọn tab **Admin**
- Các màn: Dashboard, Duyệt rút tiền, Users, Transactions, Audit Logs

## Build

```bash
npm run build
```
